# Advanced React E-Commerce App

## Project Description
This is an advanced React E-Commerce web application built using React and TypeScript. The app retrieves products from the FakeStore API and allows users to add and remove products from a shopping cart.

## Features
- Product listing from FakeStore API
- Product images, titles, and prices
- Add to Cart functionality
- Remove from Cart functionality
- Shopping cart display
- Total item count
- Total price calculation
- Checkout button
- Responsive layout

## Technologies Used
- React
- TypeScript
- Vite
- CSS
- FakeStore API

## Installation
1. Clone the repository
2. Open the project in VS Code
3. Run:

npm install

4. Start the development server:

npm run dev

## Usage
Users can browse products, add them to the shopping cart, remove products from the cart, and simulate checkout.
